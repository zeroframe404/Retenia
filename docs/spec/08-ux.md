# User experience and gamification

How Retenia feels: screen map, the Duolingo-style path, the lesson player, the review
session, the exam centre, and evidence-based gamification with a sober mode.

**Polish references:** Duolingo (path, feedback, mascot), Brilliant (interactivity inside the
explanation), Linear (density, command palette, shortcuts), Notion (block editor),
Anki/RemNote/Mochi (review), Speak/ELSA (voice), Khan Academy (mastery), Readwise Reader
(PDF/EPUB with highlights → cards).

## 1. UX principles

1. **One primary action per screen.** The home answers "what do I do today?" with one button:
   review (35 reviews, ~12 min), continue the path (lesson 7 of 40) or prepare for the exam on
   the 14th.
2. **Immediate and explainable feedback.** Every answer shows correct/incorrect, the model
   answer, "why?" (Explain my answer) and the citation to the source. **Never punish: errors
   are data.**
3. **The scheduler is visible.** Every card shows its strength (R), stability (S) and why it
   appeared today; the 4 buttons show the next interval; "Urgente" shows the cost in reviews
   before being applied.
4. **Keyboard first.** Command palette (Ctrl+K), reconfigurable shortcuts (1–4 to grade, Space
   to reveal, J/K/L in video), every drag-and-drop interaction with a keyboard alternative.
5. **Configurable density.** Compact mode (Linear) for adults; wide, animated mode for school
   students.
6. **Offline without surprises.** Everything local works with no network; anything requiring
   AI shows an estimated cost and the connection status; long operations live in a progress
   panel with cancel/resume.
7. **Accessibility built in.** WCAG 2.2 (visible focus, target ≥ 24 px, alternatives to
   dragging, AA contrast, reduced motion), screen readers (Electron's accessibility tree),
   optional fonts (Atkinson Hyperlegible, OpenDyslexic — without promising miracles: the
   evidence on "dyslexia" fonts is mixed), TTS of any text.

## 3. The path, in detail

### Anatomy of a module in the path

```
L1 → L2 → L3 → Reinforcement → L4 → L4.r1 (optional detour) → L5 → Reinforcement
   → Cumulative checkpoint → … → Mock exam (form A) → Final exam (form B)
```

- Each lesson node shows estimated minutes, concepts and state (**softly blocked / available /
  completed / completed by diagnostic**).
- The **reinforcement** composes due items of the path + items with R < 0.8 + 2–3 interleaved
  application exercises + a mini-quiz; its gate is **soft** (≥ 80 % suggests continuing; less
  offers remediation without blocking).
- The **checkpoint** every 3–4 modules is a cumulative reinforcement with interleaving.
- Completing nodes gives XP; **"Legendary"** (no hints and no word bank) is a policy variant,
  not a new node.

## 4. Evidence-based gamification

| Mechanic | Design in Retenia | Evidence / lesson |
|---|---|---|
| **Streak** | Daily goal (calculated) and streak goal separated (≈ 10 cards); "Forgot" does not count; earned freezes (1 every 6 days, bank of 2) and scheduled "holidays"; calendar and milestones. | Duolingo: users with a streak ≥ 7 went from ~17 % to > 50 % of DAU; the "streak saver" notification was the biggest jump; RemNote separates goals to avoid fragile streaks. |
| **XP and levels** | XP for lessons, reviews, reinforcements and mock exams; temporary boosts from achievements; mastery per topic (Attempted → Familiar → Proficient → Mastered) always next to the XP. | Prefer real mastery to empty levels (Khan); substance metrics alongside vanity metrics. |
| **Quests** | Daily quests (3/day: "review 20", "complete 1 lesson", "get 5 right in a row"), weekly ones, and cooperative ones when there are friends (V2). | Cooperative > competitive for social retention (Duolingo Friend Quests). |
| **Achievements** | Tied to real retention milestones (100 items "Retaining", 30 days of true retention ≥ 90 %, an exam passed) and not only to activity. | Activity badges have a small effect if they are not tied to real progress. |
| **Mascot** | A character with a state machine (Rive): it reacts to correct answers, errors, streaks and closes; configurable tone; end-of-session celebrations ("Done for today") with moderate confetti. | A consistent personality = memorability (Duo, Lily); avoid overuse. |
| **Leagues and leaderboards** | Optional, by activity level, once there is a backend (V2); friends leaderboard. | Leagues: +17 % of learning time; they demotivate whoever is at the bottom → pair by activity. |
| **Lives / energy** | **There are no hearts.** Energy only as an opt-in soft limit (Later). | Hearts were criticized for slowing learning and pushing people to pay; Duolingo replaced them with Energy in 2025. |
| **Notifications** | Maximum 2 per day, preferred hour, "streak saver", digest; copy with personality but never guilt-tripping; easy days. | "Protect the channel": optimized timing and copy are worth more than volume. |
| **Timed challenges** | Match Madness (`tap_pairs_timed`), arithmetic sprint, lightning round: reward and variety, without feeding the scheduler. | A Gardenscapes-style "moves" counter did not move retention: mechanics unrelated to learning do not work. |
| **Sober mode** | A toggle that keeps streaks, goals, heatmap and mastery; hides XP, mascot, quests and leagues; compact density. | Meta-analysis (Sailer & Homner 2020): small-to-medium effects with a novelty effect; criticism of the "electronic whip" and overjustification. Gamification by profile. |

## 5. Platform details expected in 2026

- Command palette with fuzzy search; a shortcut sheet; a global hotkey for quick capture into
  an inbox (V1); web clipper (V1).
- Tray with pending items and a badge on the icon with today's cards; optional start with the
  system.
- Multi-window, split view (PDF on the left, notes on the right with
  `react-resizable-panels`), tabs; full-screen focus mode; optional Pomodoro.
- Light/dark/system/high-contrast themes; adjustable size, line height and column width;
  reduced motion.
- Rotating backups, restorable trash, version history (V1); complete export (JSON + Markdown +
  `.apkg` + CSV).
- Localization `es-AR` first, `en`, `pt-BR`; RTL prepared; local date formats.
- Onboarding in 3 steps: choose a mode (arcade / sober), load keys (or "try without AI"),
  import (Anki / RemNote / Markdown) or create the first path.
- MCP server / local CLI so that Claude, ChatGPT or Cursor can read and create content in your
  base (V2).
